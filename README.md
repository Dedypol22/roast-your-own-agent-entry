A deterministic program that writes a 150-character one-line roast to /output/entry.txt, aimed at my own AI agent and its favourite habit: handing back a project plan, a risk register and a calendar invite for a two-step job, while the job itself waits for next quarter.

## Run it

```sh
python3 main.py
```
